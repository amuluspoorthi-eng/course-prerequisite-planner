🎓 Course Prerequisite Planner

Find a valid order for completing university courses

📌 Problem Statement

A university has several courses with prerequisite requirements. Determine a valid order in which all courses can be completed while satisfying all prerequisite requirements. If the prerequisites contain a circular dependency, report that no valid ordering exists.

3️⃣ Find Valid Ordering

⚙️ DAA Algorithm Used

Topological Sort – Kahn's Algorithm


Step 1: Calculate the indegree of every course.

Step 2: Put all courses with indegree 0 into a queue.

Step 3: Remove a course from the queue and add it to the ordering.

Step 4: Reduce the indegree of its dependent courses.

Step 5: If a dependent course becomes indegree 0, add it to the queue.

Step 6: Continue until the queue becomes empty.

Step 7: If all courses are processed, a valid ordering exists. Otherwise, a circular dependency exists.

📊 Complexity

Time Complexity: O(V + E)
Space Complexity: O(V + E)

V = Number of courses
E = Number of prerequisite relationships
